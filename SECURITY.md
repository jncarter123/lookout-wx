# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Instead, report them privately through GitHub's [private vulnerability reporting](../../security/advisories/new) for this repository.

Include steps to reproduce and the affected version or commit. You should receive a response within a week.

## Scope

This project displays alerts from the National Weather Service API. Problems with the alert data itself should be reported to the NWS, not here.
